# Бот для сравнения цен корзины (MVP)

Telegram-бот: присылаете прошлую корзину (текстом, CSV или скриншотом), бот находит те же товары или
аналоги в Пятёрочке, Самокате, Яндекс Лавке, ВкусВилле и Чижике и считает, где выйдет дешевле:
всё в одном магазине или с разбивкой на два сервиса, с учётом доставки и минимальной суммы заказа.

> ⚠️ **Цены сейчас ВЫМЫШЛЕННЫЕ** (`data/mock_catalog.json`). Это нужно, чтобы проверить логику.
> Реальных источников цен пока нет: у сервисов нет официального публичного API, см. раздел «Что не проверено».

## Структура

```
bot.py                 — Telegram-бот (точка входа)
config.py              — настройки из .env
pipeline.py            — полный цикл: разбор → сопоставление → расчёт → отчёт
models.py              — структуры данных (позиция, предложение, доставка, совпадение)
units.py               — фасовка, приведение к кг / л / шт, цена за единицу
services.py            — названия сервисов
llm.py                 — вызов Claude (ответ строго по JSON-схеме)
matching.py            — сопоставление через LLM + проверка кодом, пометки «аналог» и [uncertain]
comparison.py          — итог по сервисам, разбивка на два, экономия
report.py              — текст ответа и список для ручного заказа
parsers/               — разбор текста, CSV, скриншота
providers/             — провайдеры цен: общий интерфейс, mock, заглушки реальных сервисов (TODO)
data/                  — mock-каталог и примеры корзин
tests/                 — автоматические проверки
```

## Запуск (для новичка)

1. **Установите Python 3.10+** с https://www.python.org/downloads/ (в Windows при установке отметьте
   галочку «Add Python to PATH»). Проверка в терминале: `python --version` (в macOS/Linux — `python3 --version`).
2. **Скачайте проект**: на странице репозитория на GitHub выберите ветку, нажмите «Code → Download ZIP»
   и распакуйте архив. Откройте терминал в папке проекта.
3. **Создайте виртуальное окружение и установите зависимости**:
   - Windows:
     ```
     python -m venv .venv
     .venv\Scripts\activate
     pip install -r requirements.txt
     ```
   - macOS / Linux:
     ```
     python3 -m venv .venv
     source .venv/bin/activate
     pip install -r requirements.txt
     ```
4. **Получите токен бота**: в Telegram напишите @BotFather → `/newbot` → придумайте имя → он пришлёт токен
   вида `123456:ABC...`.
5. **(Желательно) получите ключ Anthropic API** на https://console.anthropic.com → API Keys. Вызовы платные.
   Без ключа бот тоже работает, но сопоставляет товары простым поиском по словам (все совпадения будут
   помечены [uncertain]), а скриншоты не распознаются.
6. **Создайте файл `.env`**: скопируйте `.env.example` в `.env` и впишите токены:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ANTHROPIC_API_KEY=sk-ant-...
   REGION=Москва
   ```
7. **Проверьте, что всё работает** (без Telegram и без интернета): `python -m pytest`
   — должно быть `10 passed`.
8. **Запустите бота**: `python bot.py`. Пока окно терминала открыто, бот работает. Остановить — Ctrl+C.
9. **Отправьте боту тестовую корзину**: откройте бота в Telegram, нажмите «Start» и вставьте текст из
   `data/sample_cart.txt` или отправьте файл `data/sample_cart.csv`.

### Формат текстовой корзины

```
Пятёрочка
Молоко Простоквашино 2,5% 930 мл — 2 шт — 96.99 ₽
Бананы 1 кг x2 139 руб (Самокат)
Хлеб Бородинский 400 г; 1; 55; Чижик
```
Строка с одним названием сервиса задаёт сервис для следующих строк. Фасовку пишите в названии (930 мл, 1 кг, 10 шт),
цену — за одну упаковку.

### Формат CSV

Колонки: `название;бренд;фасовка;количество;цена;сервис` (можно через запятую, английские названия тоже подходят).

## Как это работает

1. **Разбор**: текст и CSV разбираются правилами, скриншот — через Claude (распознавание изображения).
2. **Кандидаты**: провайдер каждого сервиса ищет до 5 похожих товаров.
3. **Сопоставление через LLM**: Claude выбирает «точное совпадение», «аналог» или «нет».
4. **Проверка кодом** (LLM не доверяем вслепую): несуществующие id отбрасываются; «точное» с другим брендом
   или фасовкой понижается до «аналога» с причиной; разные единицы (кг против л), неизвестная фасовка,
   низкая уверенность или цена за кг/л, отличающаяся больше чем в 2,5 раза, дают пометку **[uncertain]**.
5. **Количество**: считается по объёму — 2 × 930 мл превращаются в 2 × 950 мл или в 4 × 500 мл.
6. **Итоги**: для каждого сервиса — товары + доставка (бесплатно от порога), проверка минимальной суммы;
   лучшая разбивка на два сервиса перебором вариантов; экономия относительно того, как вы покупали.
7. **Заказ**: только вручную — бот выдаёт список с галочками и главную страницу сервиса.

## Что работает на mock-данных и что не проверено

| Часть | Статус |
|---|---|
| Цены, ассортимент, наличие | **mock (вымышленные)** — `data/mock_catalog.json` |
| Стоимость доставки, порог бесплатной доставки, минимальный заказ | **mock (вымышленные)** |
| Регион/адрес и дата цены | поля есть в каждом предложении и в условиях доставки, но mock-каталог один на все регионы |
| Адреса сайтов сервисов в инструкции | только главные страницы, **не проверены** — откройте и убедитесь сами |
| Реальные провайдеры `providers/<сервис>.py` | **заглушки с TODO**, вызывают `NotImplementedError` |
| Сопоставление через Claude | код написан по документации SDK, покрыт тестами с подменённым ответом; на живом ключе в этом репозитории не прогонялся |
| Распознавание скриншотов | зависит от качества скриншота, ошибки возможны — проверяйте список позиций в ответе |

### Риски при подключении реальных цен

- **Юридические**: у Пятёрочки, Самоката, Яндекс Лавки, ВкусВилла и Чижика нет официального публичного API
  для цен. Автоматический сбор данных с сайтов и из приложений может нарушать пользовательские соглашения;
  использование закрытых (неофициальных) API приложений — тем более. Перед подключением нужна проверка
  соглашений и, по-хорошему, консультация юриста. Легальные пути: партнёрские программы, собственные
  ручные записи цен, официальные выгрузки, если сервис их предоставляет.
- **Технические**: цены и наличие зависят от адреса, времени и промоакций, персональных скидок и карт
  лояльности; сайты защищены от ботов и часто меняются; условия доставки меняются динамически (погода,
  загрузка). Обход SMS-авторизации и антибот-защиты в проекте не делается и делаться не должен.
- **Качество сопоставления**: LLM может ошибаться (жирность, вкус, сорт), поэтому пометки «аналог» и
  [uncertain] нужно просматривать глазами. Каждый вызов Claude стоит денег: один запрос на каждую позицию корзины.

### Как подключить реальный источник позже

1. Реализуйте методы `search()` и `delivery_terms()` в `providers/<сервис>.py` (там стоят TODO).
   Каждое предложение должно содержать `region` и `fetched_at`.
2. В `providers/__init__.py` замените `MockProvider("<сервис>")` на свой класс.
Остальной код менять не нужно.
